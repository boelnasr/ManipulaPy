292 def accept(candidate: Path, root: Path) -> None: 

293 """Collect ``candidate`` only if it stays inside its own ``root``.

298 resolver's own initiative, so a URI needs no ``..`` to land outside 

299 the description directory — and ``_path_escapes_base`` resolves 

300 symlinks, so an in-tree link to an out-of-tree target is refused 

301 too.
